# Приложение «Ступени»

Каркас на Flutter: читает уроки из `content/`, помнит прогресс локально, даёт короткую проверку по готовым урокам.

Запуск из корня репозитория:

```bash
./tool/sync_content.sh
cd learner
flutter pub get
flutter run
```

Тексты правят только в `content/`. Каталог `learner/assets/content/` скрипт перезаписывает.

Карьерный трек лежит в `content/career/` и открывается с главного экрана кнопкой «Открыть карьерный трек». Лаборатория, намёки и спека капстоуна в приложение не зашиты: их открывают из репозитория. Принципы курса — в `PEDAGOGY.md` в корне.

Проверки:

```bash
./tool/sync_content.sh
cd learner
flutter test
```
