# Приложение «Ступени»

Каркас на Flutter: читает уроки из `content/`, помнит прогресс локально, даёт короткую проверку по готовым урокам.

Запуск из корня репозитория:

```bash
./tool/sync_content.sh
cd learner
flutter pub get
flutter run
```

Тексты правят только в `content/`. Каталог `learner/assets/content/` скрипт перезаписывает.

Карьерный трек лежит в `content/career/` и открывается с главного экрана кнопкой «Открыть карьерный трек». Стек найма Android для СНГ лежит в `content/android-cis/` и открывается кнопкой «Открыть стек найма Android». Лаборатории, намёки и спеки капстоунов в приложение не зашиты: их открывают из репозитория. В `pubspec.yaml` указаны только каталоги с уроками. Подкаталоги `lab`, `solutions` и `capstone` туда не добавляют: Flutter забирает файлы прямо из указанной папки, а эти подкаталоги должны остаться на компьютере. Принципы курса — в `PEDAGOGY.md` в корне.

## Словарь жаргона

Экран «Словарь жаргона» открывается с главного экрана: значок книги в верхней панели и карточка под списком треков. Внутри термины по алфавиту, поиск по слову, английскому оригиналу и формам слова, у каждого термина определение, оригинал и пример.

Данные лежат в `learner/assets/glossary/glossary.json` (в отличие от `assets/content/`, `sync_content.sh` этот файл не трогает). Формат:

```json
{
  "version": 1,
  "terms": [
    {
      "term": "Запах кода",
      "original": "code smell",
      "definition": "Простое определение по-русски.",
      "example": "Короткий пример из жизни кода.",
      "aliases": ["запахом кода", "запахом"]
    }
  ]
}
```

Чтобы добавить термин, допишите объект в `terms`: порядок не важен, приложение отсортирует само. `term`, `original`, `definition` и `example` обязательны, `aliases` (формы слова для поиска) можно не указывать. Дубли и пустые поля роняют `flutter test`. Первое упоминание термина в уроках и проверках поясняют прямо в тексте `content/`, словарь собирает те же слова в одном месте.

Проверки:

```bash
./tool/sync_content.sh
cd learner
flutter test
```

APK для телефона без локального Flutter собирает GitHub Actions. Как скачать `stupeni-learner.apk` и поставить его: [docs/apk-pipeline.md](../docs/apk-pipeline.md).
