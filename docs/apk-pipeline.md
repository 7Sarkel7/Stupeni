# Как скачать APK «Ступеней»

Приложение learner собирается в GitHub Actions и лежит в Artifacts, так же как прошивка в виде `.bin`: свой Flutter на компьютере не нужен. Workflow: [`.github/workflows/build-apk.yml`](../.github/workflows/build-apk.yml), имя в списке Actions — **Build learner APK**.

Сборка — `flutter build apk --release`. Это release-режим (без debug-баннера, дерево иконок подчищено). Подпись при этом debug-ключом: в [`learner/android/app/build.gradle.kts`](../learner/android/app/build.gradle.kts) у типа `release` стоит `signingConfig = signingConfigs.getByName("debug")`. Своего keystore и секретов в репозитории нет. Такой файл ставится на свой телефон. В Google Play его не загрузить: upload key и подпись магазина в этот пайплайн не входят.

## Когда запускается

- Push, который меняет `.github/workflows/build-apk.yml`, `learner/`, `content/` или `tool/`. Перед сборкой выполняется `./tool/sync_content.sh`: уроки копируются из `content/` в ассеты. Затем `flutter pub get` и `flutter test`. Упавший тест роняет job, APK не выкладывается.
- Вручную: Actions → **Build learner APK** → **Run workflow**. Кнопка есть, когда файл workflow уже лежит в ветке по умолчанию (`main`). Пока он только в рабочей ветке, берите APK из запуска, который создал push.

Flutter в job — stable **3.47.9** (Dart 3.13.7). Это совпадает с ограничением `sdk: ^3.13.7` в `learner/pubspec.yaml`. Более ранние 3.47.0–3.47.7 везут Dart ниже 3.13.7 и для этого pubspec не подходят.

## Скачать

1. Откройте репозиторий на GitHub.
2. Вкладка **Actions**.
3. Слева workflow **Build learner APK**.
4. Откройте зелёный запуск (сверху — самый свежий).
5. Прокрутите до блока **Artifacts**.
6. Скачайте **stupeni-learner.apk**.

Файл выкладывается как есть, без zip. Если браузер сохранил его без расширения `.apk`, допишите расширение перед установкой. Артефакт живёт столько, сколько задано в настройках репозитория (обычно до 90 дней), потом сборку нужно запустить снова.

Прямая ссылка на скачивание есть у конкретного запуска: `https://github.com/7Sarkel7/Stupeni/actions/runs/<номер>/artifacts/<id>`. Номер виден в адресе открытого запуска. Нужна учётная запись с доступом к репозиторию.

## Поставить на Android

1. Перекиньте `stupeni-learner.apk` на телефон (браузер, мессенджер, кабель).
2. Разрешите установку не из магазина. На Android 8 и новее: **Настройки → Приложения →** то приложение, которым открываете файл (Chrome, «Файлы») **→ Установка неизвестных приложений → Разрешить**. На старых версиях: **Настройки → Безопасность → Неизвестные источники**.
3. Откройте файл и нажмите **Установить**.

Каждый запуск идёт на чистой машине и подписывает APK новым debug-ключом. Поверх уже стоящей сборки Android часто отвечает «приложение не установлено» или что подписи не совпали. Удалите старые «Ступени» и поставьте файл заново. Прогресс уроков лежит в `SharedPreferences` на телефоне и при удалении пропадает.

Сеть приложению не нужна: уроки уже внутри APK.
