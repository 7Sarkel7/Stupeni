# Ступени

Учебник и приложение, чтобы освежить и дорастить навыки вокруг **Поле**: прошивка ESP32-S3, Android-пульт, позже облако на FastAPI. Тексты на русском. Это не клон Duolingo и не копия старого `learner` из Поле: уроки написаны заново, как разбор с ментором.

Днём у вас стройка, вечером — станц, эпоксидка и светодиоды. Поэтому маршрут короткий и привязан к делу, которое уже стоит на столе. База, от которой идём: Kotlin и Android уже не с нуля, C++ — на уровне «читал и чуть писал». Flutter здесь отдельный трек, не замена пульта станца.

## С чего начать

Идите по порядку, пока локальный станц не стабилен. Облако, голос и новый UI на Flutter не чинят плату, которая молчит на `GET /v1/reading`.

## Как устроен урок

1. Цель.
2. Зачем это именно станцу, а не «вообще в индустрии».
3. Теория — механизм, не лозунг.
4. Разбор на примере из пульта или прошивки.
5. Упражнения. Короткий ключ к устным вопросам — в `content/hints/`, его открывают после своей попытки.
6. Типичные ошибки.
7. Чеклист.
8. Следующий урок.

В конце каждого написанного модуля — самостоятельная работа: ТЗ, критерии приёмки, рубрика. Готового решения этой работы в репозитории нет. Проверка в приложении — четыре-пять вопросов на выбор. Она не заменяет ни устные упражнения, ни работу.

Откуда такой порядок и чего мы не копируем: [PEDAGOGY.md](PEDAGOGY.md).

## Как запустить приложение

Нужны [Flutter](https://docs.flutter.dev/get-started/install) 3.47.8+ (Dart 3.13.7, как в `learner/pubspec.yaml`; проверено на 3.47.9) и устройство, эмулятор или Chrome.

```bash
./tool/sync_content.sh
cd learner
flutter pub get
flutter run
```

`sync_content.sh` копирует `content/` в `learner/assets/content/`. Исходник уроков — только каталог `content/`. В приложении ассеты, потому что телефон не видит репозиторий на диске.

Проверка самого приложения, без устройства:

```bash
./tool/sync_content.sh
cd learner
flutter test
```

Веб, если хочется кликать с ноутбука:

```bash
cd learner
flutter run -d web-server --web-port 8080
```

Прогресс (прочитанные уроки, лучший процент проверки, спокойная серия дней) лежит в `SharedPreferences` на устройстве. Сеть приложению не нужна.

Готовый APK без Flutter на своём компьютере: [docs/apk-pipeline.md](docs/apk-pipeline.md). GitHub Actions собирает release и кладёт `stupeni-learner.apk` в Artifacts. Подпись debug-ключом, для своего телефона; магазин приложений этим файлом не закрывается.

## Что сознательно не сделано

- Нет ленты, лиг и клонирования Duolingo. Есть материал, отметка «изучил» и проверка.
- Модули 04–07 не притворяются написанными. В файле стоит **TODO** и конспект, что там будет. Самостоятельной работы у конспекта нет.
- Готовых решений самостоятельных работ и капстоуна в репозитории нет. Каркас и намёк — да.
- Это не прошивка станца и не пульт. Код в уроках — учебные фрагменты контрактов, не выгрузка репозитория Поле.
- Курс ПГС не заменяет СП, экспертизу и расчёт конкретного объекта.

## Откуда взялся маршрут

Раньше «Ступени» жили Android-приложением `learner` (`com.example.stupeni`) внутри Поле: курсы «Собери станц» и «ПГС», схема «материал → я изучил → проверка». Здесь тот же порядок сборки станца (скетч, HTTP, команда, файл, Wi-Fi, поиск в сети, BLE, облако, голос, железо) разложен по нормальным урокам и дополнен фундаментом, без которого эти шаги превращаются в угадайку. Репозиторий Поле этот PR не трогает.
