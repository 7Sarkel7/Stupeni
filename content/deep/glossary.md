# Словарь терминов

Слова, которые встречаются в главах. Каждое объяснено простыми словами. Новые термины добавляются сюда вместе с главой, где они впервые появились. Если термин встретился в главе раньше, чем вы его знаете, ищите его здесь.

| Термин | Простыми словами | Бытовая картинка |
| --- | --- | --- |
| **Корутина** (coroutine) | Работа, которую можно поставить на паузу и продолжить позже, не блокируя всё приложение | Поставили чайник и пошли делать другое |
| **Скоуп** (scope) | «Хозяин» корутин: кто их запустил и кто их отменит | Хозяйка кухни: ушла, и все дела на кухне прекратились |
| **Flow** | Поток данных: значения приходят по одному | Конвейер с коробками |
| **StateFlow** | Поток данных с одним текущим значением, оно есть всегда | Табло на вокзале |
| **ViewModel** | Объект, который хранит данные экрана и переживает поворот | Записная книжка, которая не теряется при смене комнаты |
| **Ветка** (branch) в Git | Отдельная линия снимков проекта | Черновик документа рядом с чистовиком |
| **Коммит** (commit) | Снимок проекта с подписью | Фото рабочего стола с запиской |
| **Pull Request** (PR) | Просьба на GitHub «посмотрите мои изменения и добавьте их» | Сдача тетради на проверку |
| **Ревью** (review) | Проверка чужих изменений с комментариями | Учитель проверяет тетрадь |

## Как добавлять термины

1. Объяснение — одно предложение без других незнакомых слов.
2. Бытовая картинка — из обычной жизни, не из программирования.
3. Английское слово — в скобках при первом употреблении.
