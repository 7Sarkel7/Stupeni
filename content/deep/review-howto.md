# Как сдавать задания на ревью

Практики в главах делаются локально в Android Studio. Сдаются через GitHub. Ревьюер — ИИ-агент: он читает ваши изменения и сверяет с критериями приёмки из главы.

## Один раз: подготовка

1. Заведите свой репозиторий на GitHub (публичный или закрытый). Для заданий под отдельный репозиторий-шаблон `stupeni-workbook` (появится отдельным шагом) используйте его.
2. Клонируйте его на компьютер: `git clone <адрес>`.

## Каждое задание

1. **Ветка.** Одна ветка на задание: `assignment/<глава>-<номер>`, например `assignment/cis-flow-1`.

   ```bash
   git checkout -b assignment/cis-flow-1
   ```

   **До:** вы на `main`. **После:** `git branch --show-current` показывает новую ветку.
2. **Работа.** Делайте маленькие коммиты с понятными сообщениями: что и зачем.
3. **Проверка перед сдачей.** `git status` чистый, тесты зелёные.
4. **Отправка.**

   ```bash
   git push -u origin assignment/cis-flow-1
   ```

5. **Pull Request** из этой ветки в `main` **вашего же** репозитория. В описании: что сделано; скриншот или вывод тестов; где ответы на вопросы по докам; на чём застряли.
6. **Исправления.** Новыми коммитами в ту же ветку, не новым PR.
7. **Принято** — отметьте главу на сайте и сделайте merge.

## По каким критериям смотрят

| Пункт | Что проверяется |
| --- | --- |
| Работает | Тесты зелёные, приложение запускается |
| Читается | Понятные имена, нет лишнего |
| Коммиты | Несколько, с осмысленными сообщениями |
| Доки | Ответы на вопросы по официальным докам, с цитатой |

Критерии конкретного задания всегда в конце его страницы «Практика».
