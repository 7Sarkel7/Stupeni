# 01. Фундамент

Общий язык, без которого пульт и ESP32 спорят о разных вещах. Модуль написан целиком.

Порядок. Сначала модуль Git: снимки, ежедневные команды, откат, ветки, rebase, stash, remote, pull request, секреты, устные ответы и командный вечер в отдельной песочнице. Потом язык пульта и прошивки.

1. [Как Git помнит работу](01-git.md) — снимки, SHA, HEAD, индекс, рабочее дерево.
2. [Установка, настройка, init и clone](01-git-02-setup.md) — имя, почта, редактор, переводы строк, алиасы.
3. [Снимок дня: status, add, commit](01-git-03-daily.md) — diff, сообщения, log, blame, `.gitignore`.
4. [Откат и спасение](01-git-04-undo.md) — restore, reset, revert, amend, reflog.
5. [Ветки, слияние и конфликты](01-git-05-branches.md) — fast-forward, два родителя, маркеры.
6. [Rebase и cherry-pick](01-git-06-rebase.md) — перенос коммитов, squash, fixup, один чужой патч.
7. [Stash и чужие правки](01-git-07-stash.md) — полка и отказ pull из-за локальных правок.
8. [Удалённые, теги, релизы](01-git-08-remotes.md) — fetch, pull, push, force-with-lease, тег.
9. [GitHub: PR, ревью, CI](01-git-09-github.md) — форк и ветка, проверки, git flow и короткие ветки.
10. [Ключи, секреты, IDE](01-git-10-secrets.md) — SSH, токен, утечка, LFS, Android Studio, Cursor.
11. [Вопросы с собеседования](01-git-11-interview.md) — merge и rebase, reset и revert, HEAD.
12. [Практика: командный вечер](01-git-12-project.md) — конфликт, rebase, PR, тег. Не в репозитории Ступеней.
13. [HTTP без тумана](02-http.md) — запрос, код, тело. Сначала `curl` к `/v1/reading`, потом Kotlin.
14. [JSON и текст, который JSON не является](03-json.md) — где у станции форма, где `SAVED:OK`, где объект команды.
15. [Отладка слоями](04-debug.md) — одна гипотеза, один слой, записка себе.
16. [Самостоятельная работа](05-homework.md) — свой файл вечера, рубрика, без образца в репозитории.
