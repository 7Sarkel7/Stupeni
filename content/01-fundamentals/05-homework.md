# Самостоятельная работа: протокол одного вечера

**Модуль:** 01. Фундамент  
**Уровень:** к станцу, до карьерного трека  
**Время:** один вечер, около 60 минут  
**Дальше:** [Поток, корутины и Result](../02-kotlin-android/01-coroutines.md)

## Цель

Собрать в одном своём файле три следа вечера: ветка без секрета, один ответ HTTP, одна гипотеза отладки. Файл остаётся у вас, не в репозитории Ступеней.

## Зачем это вам

Уроки модуля разбирали механизм. Работа проверяет, можете ли вы оставить после смены заметку, по которой через неделю понятно, что станц делал. Это тот же навык, что потом просят в описании PR и в баге на собеседовании. Готового образца заметки нет: иначе вы сдадите чужой вечер.

## Теория

Работайте в своём каталоге, например `~/notes/stupeni/`, или в маленьком личном репозитории. В Ступени этот файл не добавляйте и pull request с ним не открывайте.

Три части, один файл `evening.md`.

Git. Отдельная ветка от известной точки. Один коммит. Сообщение говорит, что изменилось для человека, не слово «фикс». В коммите нет пароля, ключа и `station_key`. Если экспериментируете на репозитории станца, `main` не должен стать свалкой. Если своего кода станца под рукой нет, заведите пустой репозиторий из одного `evening.md`: навык тот же.

HTTP. Один запрос с заголовками: `curl -i` к `GET /v1/reading` вашего станца. Если платы нет в этот вечер, честно напишите это и снимите `curl -i` любого другого URL, который вы понимаете (документация, `https://example.com`). В файле: код ответа, есть ли тело, ваш это станц или замена. Не подменяйте чужой сайт станцом.

Отладка. Одна гипотеза, один слой (радио, HTTP, JSON, прошивка, пульт), чем гипотеза подтвердится или умрёт. Не список из десяти догадок.

## Разбор на примере

Чего в файле быть не должно: «я починил всё», скриншот с паролем точки доступа, вставленный сюда чужой разбор из урока. Чего должно хватить: через неделю вы читаете файл и повторяете тот же `curl` или помните, почему его не было.

Урок про git уже дал короткие устные вопросы. Ключ к ним лежит отдельно и эту работу не закрывает.

## Упражнения

Сдайте себе файл `evening.md` со заголовками `Git`, `HTTP`, `Отладка`.

Критерии приёмки:

- [ ] Видно имя ветки и сообщение коммита, оба без секрета.
- [ ] Есть сырой код ответа HTTP и одна фраза, чей это сервер.
- [ ] Гипотеза одна, слой назван, сказано, какое наблюдение её закроет.
- [ ] Файл не лежит в репозитории Ступеней.

### Рубрика

| Часть | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Git | секрет в тексте или нет ветки | ветка есть, сообщение пустое | ветка и сообщение про поведение, секрета нет |
| HTTP | нет кода ответа | код есть, не сказано, чей сервер | код, тело или его отсутствие, честно назван источник |
| Отладка | список догадок | гипотеза без слоя | одна гипотеза, один слой, чем проверить |
| Честность | чужой вечер или «станц», когда платы не было | оговорки размазаны | текст совпадает с тем, что вы реально запускали |

Модуль сдан, когда нет нулей. Двойка по честности обязательна.

## Типичные ошибки

- Вставить в заметку пароль Wi-Fi «для себя».
- Списать устный ключ урока вместо своего `curl`.
- Открыть pull request в Ступени с личным логом.
- Десять гипотез, ни одной проверки.
