# Намёк. 01-git

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение самостоятельной работы модуля и не код, который можно сдать.

1. Убрать секрет из файла и из индекса, в коммит его не класть. Ранее опубликованный снимок с секретом надо считать утёкшим: секрет меняют на устройстве и в облаке, а не «затирают» новым коммитом.
2. В заголовке — поведение, не список файлов. В причине — зачем: HTTP-хендлер должен быстро ответить, кадр рисует `loop`.
3. Ветка вроде `experiment/ble-vs-tls`. Откат рабочей линии: `git checkout main`. Саму плату после этого ещё нужно прошить снимком с `main`, если вы уже залили экспериментальную прошивку. Git помнит исходник, не содержимое флеша.
