# Намёк. 04-debug

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение самостоятельной работы модуля и не код, который можно сдать.

1. Слой действия и отрисовки на плате: флаг, путь, цикл кадра, карта. Не переписываете облако, голос и кнопку, которая уже получила 200.
2. Нет даже соединения с ноутбука: радио, питание, IP, `loop`. Cleartext (передача данных по HTTP без шифрования) — про телефон, который уже умеет открыть сокет и которому Android запретил схему `http`.
3. Например: «curl GET /v1/reading → OK fw:0.9.0, телефон в SoftAP (плата сама раздаёт Wi-Fi, как маленький роутер) ещё не проверял».
