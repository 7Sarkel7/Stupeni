# Намёк. 01-git-04-undo

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. После `--soft` ветка на родителе, `git diff --staged` показывает diff снятого коммита: содержимое в индексе. После `--mixed` тот же diff в `git diff` без `--staged`, индекс совпадает с новым HEAD, диск хранит правки как неотмеченные.
2. В статусе могут быть незакоммиченные правки, `--hard` их затрёт. SHA до движения лежит в `git reflog` (строка про reset или предыдущий коммит). Имя, которое не двигает текущий `main`: `git branch rescue SHA` или `git switch -c rescue SHA`, если вы готовы на него перейти.
3. `git revert SHA`. У коллег в истории остаётся исходный коммит, они забирают новый отменяющий коммит обычным pull. Ваш локальный `--hard` их клоны не меняет, а force на общий main переписывает уже скачанную историю.
4. `git switch -c имя` пока HEAD ещё на новом коммите. Ветка указывает на него. После этого `git switch main` оставляет коммит достижимым по имени.
