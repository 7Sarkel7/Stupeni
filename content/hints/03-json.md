# Намёк. 03-json

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение самостоятельной работы модуля и не код, который можно сдать.

1. Статус — разбор префиксов `OK`, `fw:`, `board:`. Заливка — префикс `SAVED:OK:` и `substring`. Облако — JSON-парсер.
2. В LAN один запрос — один ответ HTTP, путать не с чем. Через облако ответов и команд несколько, подтверждение должно попасть в конкретное ожидание по идентификатору.
3. Команда не уходит на плату. Синтаксис JSON не равен разрешению. Человеку или полю `speak` — отказ, не тихий `eval`.
