# Намёк. 01-git-03-daily

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. После коммита `git diff --staged` пустой: индекс совпал с HEAD. `git diff` всё ещё показывает `println`, если вы ответили `n` на этот кусок. Заголовок вашего коммита — про повтор ping, без отладки.
2. Пример заголовка: `refactor: хендлер /api/display только запоминает путь`. Тело: декод GIF уехал в `loop`, иначе HTTP держит плату. Список файлов дублирует diff.
3. Изменённый отслеживаемый `secrets.env` останется в `git status`, ignore его не спрячет. `git rm --cached secrets.env`, коммит удаления из снимка, файл на диске оставить. Вчерашний коммит по-прежнему содержит секрет: его считают утёкшим и меняют значение у провайдера.
4. `git log -S` найдёт коммит, где подстрока `timeout_ms` добавилась в `status.txt`, у вас это первый коммит файла. `blame` показывает последний коммит каждой текущей строки, а не все появления строки за историю.
