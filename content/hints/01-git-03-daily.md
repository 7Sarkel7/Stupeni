# Намёк. 01-git-03-daily

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. После коммита (сохранённый в Git снимок изменений с подписью) `git diff --staged` пустой: индекс совпал с HEAD (указатель Git на коммит, на котором вы сейчас стоите). `git diff` всё ещё показывает `println`, если вы ответили `n` на этот кусок. Заголовок вашего коммита — про повтор ping, без отладки (отладка, дебаг — поиск причины ошибки: остановка программы, просмотр значений, логов).
2. Пример заголовка: `refactor: хендлер /v1/publish только запоминает путь`. Тело: разбор журнала уехал в `loop`, иначе HTTP держит плату. Список файлов дублирует diff (дифф — список отличий между двумя версиями файла: что добавили, что убрали).
3. Изменённый отслеживаемый `secrets.env` останется в `git status`, ignore его не спрячет. `git rm --cached secrets.env`, коммит удаления из снимка, файл на диске оставить. Вчерашний коммит по-прежнему содержит секрет: его считают утёкшим и меняют значение у провайдера.
4. `git log -S` найдёт коммит, где подстрока `timeout_ms` добавилась в `status.txt`, у вас это первый коммит файла. `blame` показывает последний коммит каждой текущей строки, а не все появления строки за историю.
