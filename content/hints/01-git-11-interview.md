# Намёк. 01-git-11-interview

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. Пока `main` впереди, merge даёт коммит с двумя родителями, старые SHA живы. Rebase переносит ваши коммиты поверх нового `main`, это уже другие SHA. Fast-forward бывает, когда двигать нужно только указатель.
2. На общем `main` — `git revert SHA` и обычный `git push`. Amend и `--force-with-lease` уместны на своей ветке, когда переписываете коммит, который не стал базой для чужой работы, и об этом написано в PR.
3. `git fetch` только скачает объекты и обновит `origin/*`, грязные файлы останутся. `git pull` ещё и вливает: на тех же файлах получите отказ `would be overwritten` либо коммит слияния, если дерево чистое и вы разъехались.
4. Тег вперёд не едет, коммит в detached HEAD тег не двигает. Сохранить эксперимент: `git switch -c experiment/from-tag`, не уходя на `main` раньше.
