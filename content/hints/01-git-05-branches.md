# Намёк. 01-git-05-branches

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. Если на `main` не было своих коммитов после ответвления, merge напечатает `Fast-forward`, а граф останется прямой линией. Коммит с двумя родителями выглядит как развилка `|\` и сходится в одном узле.
2. `--theirs` забрал бы только сторону ветки и выбросил бы лишнюю строку с `main`, если её не было в том коммите. Ручная сборка оставляет обе мысли: выбранный таймаут и строку, которую добавила другая сторона.
3. Над чертой — текущая ветка, у вас это `main`, сторона ours. Под чертой — `feature/fields`, сторона theirs.
4. `git diff main...feature` с тремя точками. Две точки сравнивают кончики и подмешают коммиты, которые есть только на `main`.
