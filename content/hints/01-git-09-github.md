# Намёк. 01-git-09-github

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. В описании есть поведение: хендлер больше не декодирует GIF, только путь и флаг. Проверка: POST с путём, ответ быстрый, кадр рисует цикл прошивки. Вне PR: сам декодер, облако, секреты, переформатирование несвязанных файлов.
2. Amend меняет SHA, на который уже ссылается комментарий. Ревьюер видит другой коммит и теряет нитку. Новый коммит оставляет замечание и ответ рядом. Переписывание — только по явной просьбе и с force-with-lease.
3. Открывают шаг `flutter test` (или тот, что красный) и читают первое сообщение падения. Re-run повторяет тот же коммит. Починка — коммит с исправлением и новый push.
4. Квартальная прошивка с `develop` — git flow. Ежедневные вливания в `main` — trunk-based. Вопрос для станции: как часто вы готовы прошивать и кто ещё клонирует репозиторий. Один человек вечером обычно живёт короткими ветками от `main`.
