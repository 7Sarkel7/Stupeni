# Намёк. 01-git-08-remotes

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. После fetch статус может показать `behind`, файлы те же, пока вы не влили. Меняет файлы `git pull`, `git merge origin/main` или `git rebase origin/main`.
2. Lease сверяет кончик ветки на сервере с вашей закладкой `origin/ветка`. Если коллега запушил (пуш — отправка ваших коммитов на сервер, например на GitHub) коммит (сохранённый в Git снимок изменений с подписью), а вы его не фетчили, закладка старая, lease откажется. Голый `--force` передвинет ветку на ваш SHA (SHA, хеш — уникальный идентификатор коммита из букв и цифр) и снимет с кончика чужой коммит.
3. `main` двигается с каждым новым коммитом, тег (постоянная метка на коммите, обычно с номером версии) остаётся на выпуске. Через месяц: `git fetch --tags` или `git fetch`, затем `git switch --detach v0.1.0`.
4. Не хватило `git push origin v0.1.0`. Push без аргументов отправил ветку, за которой вы следите, не тег.
