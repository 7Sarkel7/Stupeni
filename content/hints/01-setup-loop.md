# Намёк. 01-setup-loop

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение самостоятельной работы модуля и не код, который можно сдать.

1. Каркас зовёт `loop` с маленькой буквы. `Loop` — чужая функция, её не вызовут. Плата молчит при успешной компиляции.
2. Колбэк (функция, которую вызовут позже, когда что-то произойдёт) должен быть коротким. Ожидание Wi-Fi держит контекст, в котором нельзя застрять, и не даёт `loop` обслуживать HTTP. Правильно: запомнить SSID (имя Wi-Fi-сети), поставить флаг, соединяться из `loop`.
3. Глобал в заголовке виден всем и легко получить несколько определений. `static` в `.cpp` ограничивает имя этим файлом. Меньше шансов, что два модуля спорят за один флаг.
