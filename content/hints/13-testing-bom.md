# Намёк. 13-testing-bom

Откройте после своей попытки. Номера библиотек здесь нет специально.

1. Согласованные версии тех строк Compose, которые вы объявили без номера. Сама платформа библиотеки в APK (файл установки приложения для Android) не добавляет. Navigation 3, Activity и Lifecycle в этот набор не входят.
2. На страницу BOM («список версий»: подключаете его один раз, и версии связанных библиотек подбираются сами) developer.android.com. Урок к тому времени может отстать, страница — нет.
3. UI-тест (UI — пользовательский интерфейс: всё, что видит и нажимает человек) на `createComposeRule` ловит кнопку и видимую фразу. Чистая `describePing` ловит правило «обрыв → станция не ответила» без устройства.
