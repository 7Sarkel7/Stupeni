# Намёк. 01-git-10-secrets

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. В GitHub вставляют `~/.ssh/id_ed25519.pub`. Закрытый — `~/.ssh/id_ed25519`, без `.pub`. Фраза запирает закрытый файл: копия с украденного диска без фразы не подписывает сессию. Ключ всё равно удаляют в настройках GitHub, фраза только выигрывает время.
2. Revoke токена (секретная строка-пропуск, которая подтверждает, кто вы) в Developer settings и убрать URL (адрес ресурса в интернете) с секретом из `.git/config` (`git remote set-url origin https://github.com/you/station.git`). Коммит (сохранённый в Git снимок изменений с подписью) не отзывает токен на сервере. Кто скопировал строку, пользуется ею, пока revoke не прошёл.
3. Коллеге этот репозиторий отдавать как «чистый» нельзя: `git log -S` находит фальшивку в старом коммите. Если строка была паролем, пароль уже утёк: его меняют, историю считают грязной, ignore закрывает только будущие добавления.
4. Без клиента LFS на диске текстовый pointer, не кадры gif. Ключ подписи в LFS остаётся секретом в отдельном хранилище и в истории указателей: его место — вне git, с бэкапом (резервная копия на случай потери данных) не в репозитории.
