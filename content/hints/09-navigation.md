# Намёк. 09-navigation

Откройте после своей попытки.

1. Ключ статуса и поверх него ключ файлов. В стеке нет байтов журнала, списка каталога и клиента.
2. В лист передают `onOpenFiles`. Вызов перехода живёт рядом со стеком, в тесте лямбда пустая или считает вызовы.
3. Новый пульт — Navigation 3, номер со страницы релизов `navigation3`. В старых репозиториях всё ещё читают Navigation Compose с `NavHost`. Номера из урока нет.
