# Намёк. 01-git-06-rebase

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. Останется сообщение первого коммита, у вас это `wip`, если вы не ставили `reword`. Diff второго вошёл в него. SHA новый, потому что родитель, дерево или состав объекта уже не те, что у старого `wip`. Старый SHA ещё в `git reflog`.
2. Верхний блок — `main`, база rebase. `--ours` в этот момент тоже `main`. Ваш таймаут 800 лежит в нижнем блоке. Слепой `--ours` оставит число из `main` и выбросит задачу ветки.
3. Нужен push, который заменит ветку на сервере только если там всё ещё тот кончик, который вы видели. Голый `--force` затрёт чужой коммит, если коллега успел запушить в ту же ветку. Имя осторожной команды — `--force-with-lease`.
4. `git cherry-pick SHA`, стоя на `main`. В `git log` это новый хеш. Сообщение можно оставить прежним, родитель — кончик `main`, не исходная ветка.
