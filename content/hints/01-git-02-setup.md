# Намёк. 01-git-02-setup

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение практической работы модуля.

1. Путь из `--show-origin` для глобальной настройки — файл вроде `/home/you/.gitconfig` или `C:/Users/you/.gitconfig`. Пустая почта не мешает коммиту: Git подставит имя машины и логин. В ревью автор будет «чужой», поправить уже записанные коммиты можно только переписыванием истории.
2. На Windows для курса годится `true`: в индекс уходит LF. На macOS и Linux — `input`. `.gitattributes` с `eol=lf` лежит в репозитории, поэтому правило не зависит от того, что человек забыл про глобальный конфиг.
3. Алиас `st` записан в `~/.gitconfig` (`--global`). Push отправляет коммиты, не ваш глобальный конфиг. У коллеги `git st` заработает, только если он сам заведёт алиас.
4. У клона уже есть коммиты, ветка следит за `origin/main`, в `.git/config` прописан remote. У `git init` истории нет, пока вы сами не сделаете первый коммит, и remote нет, пока вы его не добавите.
