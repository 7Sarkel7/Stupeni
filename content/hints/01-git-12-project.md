# Намёк. 01-git-12-project

Откройте после своей попытки. Здесь вид результата и ответы на вопросы вечера, не скрипт, который выполняет шаги за вас.

1. Перед слиянием локальный `main` догоняют `git pull --ff-only`, чтобы коммит коллеги с `model` был на первой линии, а не сбоку. После `merge --no-ff` на графе узел слияния, под ним коммит `docs` и осмысленный `feat` (не три `wip`). После squash на `main` один новый коммит с общим diff. Тег `v0.1.0` стоит на выпуске, `git show v0.1.0` печатает сообщение про timeout 800 и model. Точный `--stat` зависит от способа вливания: смотрите свой вывод.
2. `--ours` во время rebase — это `origin/main`, таймаут 3000 и model. Ваши 800 лежат в нижнем блоке. Целиком `--ours` оставит 3000.
3. Amend заменит SHA, на который ссылается комментарий. Force-with-lease обновит ветку, только если чужого коммита сверху не было, и всё равно оторвёт обсуждение от старого патча. Новый коммит `docs:` оставляет и замечание, и ответ.
4. Перед последним push `git status` не должен показывать `.env` как файл к коммиту. Если GitHub не открывали, описание лежит в `pr.md` и прямо говорит, что страницы PR не было.
