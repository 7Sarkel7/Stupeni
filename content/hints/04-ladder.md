# Намёк. 04-ladder

Откройте после своей попытки. Это короткий ключ к устным вопросам урока, не решение самостоятельной работы модуля и не код, который можно сдать.

1. BLE (экономичный режим Bluetooth для маленьких устройств) оставить для пароля и секрета. Файл идёт HTTP на карту, кадр рисует плата. Покадровый BLE не нужен и не влезает во вменяемое время.
2. Запись короткими кусками с проверкой длины `write` и сверка CRC32 (контрольная сумма, по которой проверяют, что данные не испортились) с отказом сохранять битый файл. Плюс мьютекс («замок»: пока один поток им владеет, остальные ждут, не трогая общие данные), чтобы параллельный кадр не рвал FAT.
3. Белый список на сервере реле или на телефоне до отправки. `stationDo*` на плате не получает неизвестное имя, если верхний слой живой. Даже если получит — ветка `unknown`, карта не форматируется. Голос не повод заводить новую функцию.
