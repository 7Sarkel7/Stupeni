# 02. Kotlin и Android: пульт станца

Пульт — клиент локального HTTP. Модуль написан целиком и опирается на фундамент: сначала `curl`, потом кнопка.

Порядок:

1. [Поток, корутины и Result](01-coroutines.md) — сеть не в `onClick`.
2. [OkHttp, таймауты и cleartext](02-okhttp.md) — отдельный клиент LAN, схема `http://`.
3. [Одна команда: показать файл](03-display.md) — форма `path`, код 400, то же действие позже вызовет облако.
4. [Состояние пульта и ошибка человеку](04-state.md) — IP пережил убийство процесса, фраза говорит, что случилось.
5. [Самостоятельная: фраза вместо трассы](05-homework.md) — строка для человека, пишете у себя, в этом репозитории тела функции нет.
6. [Composable: экран пульта](06-composables.md) — Material 3, Activity только вызывает `setContent`.
7. [Состояние: remember и подъём](07-remember.md) — черновик поля и хозяин строки.
8. [Побочные эффекты](08-effects.md) — сокет не в теле composable.
9. [Навигация Compose](09-navigation.md) — статус и список файлов, Navigation 3 для нового кода.
10. [ViewModel и экран](10-viewmodel-compose.md) — `StateFlow` и `collectAsStateWithLifecycle`.
11. [Список файлов: LazyColumn](11-lazy-column.md) — ключ-путь, пустая карта отдельно от обрыва.
12. [Тема Material 3](12-material3.md) — одна схема на пульт.
13. [Тест UI и BOM](13-testing-bom.md) — кадр без платы, номер BOM со страницы документации.
14. [Самостоятельная: пульт на Compose](14-homework-compose.md) — свой проект вне Ступеней. Kotlin Multiplatform там необязательный шаг после Android-экрана.

Прошивку можно открыть параллельно с вечерами Compose, если плата уже на столе: [модуль 03](../03-cpp-esp32/README.md). Экран плату не чинит. Номера библиотек сверяют с [документацией Compose](https://developer.android.com/develop/ui/compose/documentation), не с застывшей строкой в уроке.
