## Цель

Писать `if` и `when` как выражения, выбрать нужный цикл, объявить функцию со значениями по умолчанию и именованными аргументами. Подготовить руку к лямбдам: функция в Kotlin — полноценное значение.

## Зачем это вам

`when` встречается в каждом редьюсере и в каждом `sealed`-состоянии экрана. Именованные аргументы читаются в Compose на каждой строке: `Text(text = "Привет", maxLines = 1)`. Значения по умолчанию объясняют, почему у composable десять параметров и вызывают его одним.

## Теория

**if как выражение.** `val label = if (online) "в сети" else "нет связи"`. Ветка `else` обязательна, когда результат присваивают.

**when.** Замена цепочки `if`. Тоже выражение.

```kotlin
fun describe(code: Int): String = when (code) {
    200 -> "ок"
    in 400..499 -> "ошибка клиента"
    500, 502, 503 -> "сервер"
    else -> "неизвестно"
}
```

Без аргумента: `when { x < 0 -> ...; x == 0 -> ...; else -> ... }`. Если `when` разбирает `enum` или `sealed` и используется как выражение, `else` не нужен: компилятор проверит, что перечислены все варианты. Новый вариант в `sealed` сломает сборку там, где вы его забыли, и это хорошо.

**Циклы.**

- `for (i in 0 until n)` — от 0 до `n - 1`. `0..n` включает `n`. `downTo`, `step` — для обратного порядка и шага.
- `for (item in list)`, `for ((index, item) in list.withIndex())`.
- `while`, `do while` — когда число шагов заранее неизвестно.
- `break`, `continue`; метка `outer@ for (...)` и `break@outer` для вложенных циклов.

Но на данных чаще пишут не цикл, а [операторы коллекций](08-collection-operators.md).

**Функции.**

```kotlin
fun connect(host: String, port: Int = 80, timeoutMs: Long = 3_000): Boolean { ... }

connect("192.168.10.1")
connect("192.168.10.1", timeoutMs = 500)
```

- Значения по умолчанию заменяют перегрузки.
- Именованные аргументы можно переставлять и пропускать те, у кого есть значение по умолчанию.
- Однострочная функция: `fun double(x: Int) = x * 2`.
- Возвращаемый тип `Unit` можно не писать.
- Локальные функции разрешены: функция внутри функции видит переменные внешней. Это первый шаг к замыканиям из [урока 06](06-capture-inline.md).

**Функция как значение.** `fun double(x: Int) = x * 2` можно передать куда-то по ссылке: `::double`. Дальше курс объясняет, как.

## Разбор на примере

Состояние пульта и его текст:

```kotlin
enum class Link { Idle, Connecting, Online, Failed }

fun statusText(link: Link, attempt: Int = 0): String = when (link) {
    Link.Idle -> "не подключено"
    Link.Connecting -> "подключаюсь, попытка ${attempt + 1}"
    Link.Online -> "в сети"
    Link.Failed -> "нет связи"
}
```

Нет `else`: добавьте `Link.Paused`, и `statusText` не соберётся, пока вы не решите, что показывать.

## Упражнения

1. Напишите `fun grade(score: Int): String` через `when` с диапазонами: до 49 — «ещё нет», 50–79 — «хорошо», 80–100 — «отлично», иначе — «неверный балл».
2. Выведите числа от 10 до 0 с шагом 2 и найдите, на каком числе остановится цикл.
3. Объявите `fun send(path: String, retries: Int = 3, verbose: Boolean = false)` и вызовите тремя способами: только `path`; с `verbose = true`; с обоими именованными в обратном порядке.
4. Возьмите `enum class` из разбора, уберите одну ветку `when` и прочитайте ошибку компилятора.
5. Вложенный цикл ищет первую пару `a * b == 24`, `a, b` от 1 до 10. Остановите оба цикла меткой.

### Самопроверка

- Можете объяснить, почему `when` без `else` по `sealed` полезнее, чем с `else`.
- Различаете `0 until 3` и `0..3`.

## Типичные ошибки

- `else ->` в `when` по `sealed`, который прячет новый вариант.
- `0..list.size` вместо `0 until list.size` (или `list.indices`) и выход за границу.
- Десять перегрузок вместо значений по умолчанию.
- Именованные аргументы смешаны с позиционными в неудобном порядке.
