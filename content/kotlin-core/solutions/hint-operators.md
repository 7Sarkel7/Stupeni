# Намёк. Операторы и extension

Не открывайте, пока не попробовали сами.

`averageByDevice`: сначала избавьтесь от показаний без температуры и заодно сделайте из них пары «устройство и число», потом сгруппируйте по устройству, потом посчитайте среднее в каждой группе. Устройства без данных выпадут сами, если фильтр стоит до группировки.

`initials`: режьте строку по пробельным кускам, пустые куски выбрасывайте, у каждого берите первую букву и поднимайте регистр. Для строки из одних пробелов получится пустая строка.

`secondOrNull`: подумайте, нет ли у списка безопасного обращения по индексу, которое не бросает исключение.
