# Намёк. Лямбды

Не открывайте, пока не попробовали сами.

`applyTwice`: параметр `f` — обычная функция, её вызывают с круглыми скобками. Результат первого вызова — вход второго.

`repeatIndexed`: обычный цикл по индексам, внутри вызов параметра. При нуле и отрицательном числе цикл просто не выполнится, отдельная проверка не нужна.

`compose`: верните лямбду с одним параметром. Внутри она сначала вызывает первую функцию, потом вторую от её результата.

`makeCounter`: переменная объявлена до `return`, лямбда читает и увеличивает её. Подумайте, что вернёт выражение «увеличить и отдать»: нужно сначала отдать текущее значение, потом сдвинуть.

`notifyIfPresent`: сравнение с `null` или `?.invoke`. Булев результат должен говорить, была ли лямбда, а не что она вернула.

`firstSuccess`: цикл по номерам попыток; как только результат не `null`, выходите из функции. После цикла вернуть `null`.
