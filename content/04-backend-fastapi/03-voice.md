## Цель

Провести фразу человека до уже существующей команды и отсечь всё остальное.

## Зачем это в маршруте

Голос на учебной метеостанции — надстройка над таблицей `publish` / `idle` / …. Распознавание речи на телефоне, модель на сервере, действие на плате. ESP не место для большой модели.

## Что будет в полном уроке

- Пробуждающее имя: чужие фразы не уходят в API (набор правил, по которым одна программа обращается к другой).
- Имя без хвоста команды — «слушаю», а не пустой запрос.
- Ответ модели: `speak`, `cue` (короткий файл на карте), `actions[]` с именами из белого списка.
- Отказ на `format_sd` и любой неизвестный `command`, даже если JSON валидный.
- Захардкоженный (хардкод — значение, вписанное прямо в код вместо настроек или параметров) путь «станция, тише» до подключения модели.
- Что произносит телефон (`speak`) и что играет станция (файл с карты). Это разные устройства.
- Список файлов с платы до того, как модель назовёт `path`, чтобы не показывать несуществующее.
