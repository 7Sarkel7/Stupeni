## Цель

Сохранить одну заметку из сети в Room и показать её без сети. Свёртку очереди сдать лабораторной.

## Зачем это вам

Капстоун потребует batch, фото и конфликт. Если цепочка «Retrofit → Room → Flow → экран» ни разу не заработала на маленьком JSON, журнал смены утонет в трёх библиотеках сразу. Этот вечер оставляет одну сущность и один GET.

## Теория

Источник JSON — публичный учебный адрес без ключа, например один объект с полем заголовка. Адрес записывают в README `hire-scratch`. Чужой сервер может исчезнуть: тогда положите в проект локальный файл-пример и читайте его тем же репозиторием через интерфейс. Интерфейс важнее конкретного хоста.

Очередь исходящих в этом приложении можно не рисовать. Её правила уже в `OutboxTest`. В `smena` их реализуют заново.

## Разбор на примере

Сущность `ScratchNote`: внешний id и заголовок. Больше полей не нужно. DataStore хранит миллисекунды последнего успеха. Экран показывает заголовок и время. Самолётный режим после одного успеха оставляет заголовок на экране. Первая ошибка при пустой базе показывает фразу, не трассу.

## Упражнения

```bash
cd content/android-cis/lab
./gradlew test --tests dev.stupeni.hire.OutboxTest
```

В `hire-scratch`:

- [ ] Интерфейс Retrofit с одним suspend-методом.
- [ ] У OkHttp заданы таймауты, числа есть в README.
- [ ] Room: одна сущность, DAO отдаёт `Flow`, вставка suspend.
- [ ] После успеха экран читает базу, не объект ответа напрямую.
- [ ] Повторный запуск без сети показывает прошлую строку.
- [ ] Время успеха лежит в DataStore и переживает процесс.
- [ ] JPEG и очередь batch в этот проект не добавляли.
- [ ] Граф Hilt отдаёт API, базу и DataStore. ViewModel их не собирает через `new`.

### Рубрика

| Часть | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Лаборатория | `OutboxTest` красный | зелёный, CREATE+DELETE путаете | зелёный, правила рассказываете на двух id |
| Офлайн | без сети список пустой, хотя успех уже был | строка есть, пока процесс жив | строка есть после перезапуска без сети |
| Шов | кадр рисует DTO Retrofit | база есть, экран иногда читает ответ | экран подписан на Flow базы |
| Сеть | таймаута нет | таймаут есть, в README не записан | таймаут в коде и в README, ошибка — фраза |
| Честность | скопирован чужой клиент целиком | намёк открыт сразу | свой модуль, намёк после попытки или закрыт |

Ноль по любой строке — к тестам рано.

## Типичные ошибки

- Начать `smena` вместо этого короткого GET.
- Записать токен в репозиторий, хотя учебному JSON он не нужен.
- Выключить таймаут, потому что «на эмуляторе и так быстро».
