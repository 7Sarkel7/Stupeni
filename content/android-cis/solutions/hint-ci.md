# Намёк. Workflow

Готового файла здесь нет. Свой соберите и подставьте каталог, где лежит `gradlew`.

- Запуск на push (пуш — отправка ваших коммитов на сервер, например на GitHub) и на pull request (просьба на GitHub проверить ваши изменения и добавить их в основную ветку).
- Машина Ubuntu.
- Checkout (чекаут — переключение рабочей папки на другую ветку или коммит) репозитория.
- JDK той версии, которой проект собирается локально. В README та же цифра.
- Команда юнит-тестов. Если `gradlew` не в корне, шаг выполняется из его каталога.
- Эмулятор не требуется.
- Секреты, keystore и bearer в файл не кладут.
- Версии действий `checkout` и `setup-java` смотрят в Marketplace в день коммита (сохранённый в Git снимок изменений с подписью). Число из чужого урока двухлетней давности не копируют.
- Красный шаг не комментируют. Чинят тест или код.
