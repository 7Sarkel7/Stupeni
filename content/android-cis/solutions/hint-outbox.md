# Намёк. Очередь

Не открывайте, пока не попробовали сами.

Одна ячейка на `localId`, в ответе порядок первого появления. Ревизия с единицы и каждый следующий шаг по этому id строго больше предыдущего. Пустой id — ошибка аргумента.

CREATE, затем UPDATE остаётся CREATE с новой ревизией. CREATE, затем DELETE снимает ячейку. UPDATE, затем UPDATE оставляет последний UPDATE. UPDATE, затем DELETE становится DELETE. DELETE, затем CREATE становится CREATE. Второй CREATE подряд, второй DELETE подряд и UPDATE после DELETE — ошибка аргумента.
