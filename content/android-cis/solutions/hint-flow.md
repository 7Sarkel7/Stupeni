# Намёк. Заголовок и последняя версия

Не открывайте, пока не попробовали сами.

Пробелы по краям снимают. Подряд идущие пробелы и переводы строк внутри становятся одним пробелом. Пустая строка так и остаётся пустой. Длину считают по `String.length` уже после сжатия пробелов. Всё, что длиннее восьмидесяти символов, отрезают, без многоточия.

Одинаковый id живёт одной ячейкой. Побеждает больший `updatedAt`. При равенстве остаётся тот элемент, который в списке стоял позже. Пустой id выбрасывают. Порядок ответа — порядок первого появления id, не сортировка по времени.
