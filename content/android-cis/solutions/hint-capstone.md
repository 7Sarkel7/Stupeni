# Намёк. Смена

Не открывайте, пока одна веха не простояла около 40 минут.

Идите по слоям спеки. Сначала запись, которая жива в авиарежиме. Потом один файл фото и настройки. Потом контракт, который повторяет `curl`. Потом уникальная фоновая работа. Потом тесты. Потом уведомление.

Очередь перед отправкой сверните так же, как в лаборатории трека: пара «создал и тут же удалил» на сервер не едет. Конфликт — две кнопки, не склейка строк.

Пуш и локальные часы показывают уведомление одним классом. Сервис пуша только разбирает data-карту и ставит уже существующую синхронизацию.

Сервер может быть коротким. В README должна быть команда, которой его поднимает другой человек. Токен в пример не вставляют.

Готового экрана, Gradle-проекта и workflow в этом файле нет.
