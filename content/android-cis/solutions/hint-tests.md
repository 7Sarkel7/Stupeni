# Намёк. Три проверки

Не открывайте, пока не попробовали сами.

Репозиторий в тесте — мок (мок, фейк — подставной объект для теста вместо настоящей зависимости: сервера, платы или базы) интерфейса, не настоящая база. Ответ сохранения задают до вызова. Снимок читают из `StateFlow` ожиданием первого значения после действия и отменой в конце. Пока фаза «сохраняю», второй вызов не приводит ко второму сохранению: это видно по счётчику вызовов мока.

Кадр собирают готовым снимком. Ищут текст пустого состояния и текст места. `viewModel()` в этом тесте не вызывают.

Эмулятор в GitHub Actions для этих юнит-тестов не поднимают. Тест кадра остаётся локальным, команда записана в README.
