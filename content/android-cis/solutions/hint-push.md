# Намёк. Разбор data-пуша

Не открывайте, пока не попробовали сами.

Ключ типа читают точно, с учётом регистра. `shift_reminder` — напоминание, лишние ключи не мешают. `sync_nudge` требует `pending`: либо `0`, либо число без плюса, пробела и ведущего нуля. Всё остальное, включая пустой тип, чужой регистр и отрицательное число, становится тихим игнором. Исключение из разбора не бросают: сервис от этого не должен падать.

Уведомление показывает один класс и для локальных часов, и для пуша (отправка ваших коммитов на сервер, например на GitHub). В сервисе нет запроса к серверу журнала. Для nudge ставят ту же уникальную синхронизацию, что и кнопка.

Номер SDK (набор инструментов для разработки под платформу) RuStore и номер Firebase BoM берут с их страниц в день проекта. В намёке чисел нет специально.
