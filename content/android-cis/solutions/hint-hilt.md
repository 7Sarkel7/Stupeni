# Намёк. Граф

Не открывайте, пока не попробовали сами.

Часы — интерфейс с одним методом «сейчас». Реализацию отдаёт модуль. ViewModel просит интерфейс в конструкторе и не вызывает `System.currentTimeMillis` сама. Activity помечена точкой входа и не собирает репозиторий через `new`.

В тесте без устройства тот же конструктор получает ручные часы. Отдельный UI-граф (UI — пользовательский интерфейс: всё, что видит и нажимает человек) для этого вечера не нужен.

Koin в этот репозиторий не добавляют. В README одной фразой: тот же интерфейс в Koin был бы `single` или `factory`, экран — `viewModel`.
