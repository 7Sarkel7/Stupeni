# Намёк. Описание PR

Готового текста, который можно вставить в GitHub, здесь нет. Свой черновик сверьте со списком. Если пункта нет, допишите своими словами.

- Зачем: какой сбой на столе или какой тест был дырявый.
- Что сделано: одна причина, без пересказа каждого файла.
- Как проверить: команда или два шага, которые повторит другой человек.
- Чего не делали, если это легко перепутать. Для повтора чтения статуса явно скажите, что запись лампы вы не повторяете.
- Нет пароля, нет «починил сеть», нет второй несвязанной правки.

Плохой заголовок, который не сдавайте: «фикс» (исправление ошибки; хотфикс — срочное исправление, которое выпускают без ожидания обычного релиза). По нему нельзя проверить поведение.
